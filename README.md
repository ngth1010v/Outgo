# Outgo

A lightweight, fast-starting expense tracker for Android — track spending, income, and transfers
across multiple accounts, set budgets and savings goals, and see where your money goes.

## Download

1. Go to the [Releases page](https://github.com/ngth1010v/Outgo/releases/latest).
2. Download the latest `app-release.apk`.
3. Open the downloaded file on your Android phone to install it.
   - Android will ask permission to install from this source the first time — allow it, then tap
     **Install**.
4. Open **Outgo** from your app drawer.

Requires Android 11 (API 30) or newer.

## Features

- Track expenses, income, and transfers between accounts
- Multiple accounts, including savings accounts with a monthly target
- Per-category monthly budgets with progress bars
- Home dashboard: total balance, budgets, savings progress, last-5-months chart
- Analysis screen: month-over-month comparison, top income/expense categories
- Custom category icons, English and Vietnamese language support
- Full backup/restore to a single file
